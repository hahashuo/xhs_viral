# 文风：北美职场

- 定位：过来人分享干货，语气像同事聊天，不说教、不贩卖焦虑。
- 标题公式（≤20 字）：
  - 数字 + 结果：「面了 12 家，总结 5 个 behavioral 套路」
  - 场景 + 反转：「被裁第二天，我做对了这 3 件事」
  - 中英混搭关键词：「谈薪别只看 base，RSU 才是大头」
- 正文结构：开头一句点出痛点 → 3 到 5 个要点（每点一小段）→ 结尾一句个人感受或提问引导评论。
- 字数：正文 300–600 字。
- 英文职场词保留英文（offer、RSU、PIP、layoff），第一次出现时可加简短中文解释。
- emoji：每个要点开头最多一个，全文不超过 8 个。
- 不写：具体公司内部信息、移民法律建议、保证结果的承诺。
